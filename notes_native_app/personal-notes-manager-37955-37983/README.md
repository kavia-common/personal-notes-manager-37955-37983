# personal-notes-manager-37955-37983

This workspace contains the native Personal Notes application.

- App path: notes_native_app
- See detailed instructions and features: notes_native_app/README.md

Quick start:
1) cd notes_native_app
2) mkdir -p build && cd build
3) cmake .. && cmake --build . -j
4) ./MainApp   (or `cmake --build . --target run`)
